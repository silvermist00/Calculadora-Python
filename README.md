# Calculadora Python

Projeto desenvolvido em Python com o objetivo de praticar conceitos básicos de programação.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Tratamento de divisão por zero

## Tecnologias utilizadas

- Python 3

## Como executar

1. Clone o repositório
2. Execute o arquivo:

```bash
python calculadora.py
```
